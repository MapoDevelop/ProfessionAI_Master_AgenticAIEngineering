# 🤖 Agentic AI Engineering

Repository personale per il **[Master in Agentic AI Engineering](https://profession.ai/master/agentic-ai-engineering)** di [Profession AI](https://profession.ai) — appunti, esercizi e project work svolti durante il corso.

## 📌 Il corso

Il master forma professionisti capaci di progettare, orchestrare e mettere in produzione **sistemi multi-agente autonomi**, padroneggiando i principali framework per agenti AI (LangChain, CrewAI, AutoGen) con un focus concreto su sicurezza e governance in produzione.

**In breve:**

- 🎓 250 ore tra teoria e progetti, accesso a vita
- 🛠️ 5 project work con casi reali da portfolio
- 🏆 Certificazione ICEP EU, riconosciuta in 27 paesi europei

## 📚 Programma

Il percorso è suddiviso in 5 moduli:

1. **Programmazione con Python** — strutture dati, OOP, librerie scientifiche
2. **Tecniche di coding avanzate** — pattern architetturali, programmazione asincrona, testing
3. **Fondamenti di Agentic AI** — architetture LLM, prompt engineering, tool use, ReAct
4. **Multi-agent system** — orchestrazione, CrewAI, AutoGen, coordinamento tra agenti
5. **AI Agents Deployment & Security** — containerizzazione, monitoring, sicurezza, prompt injection

## 🧰 Tecnologie

`Python` · `LangChain` · `CrewAI` · `AutoGen` · `LlamaIndex` · `RAG` · `Docker` · `API Gateway`
